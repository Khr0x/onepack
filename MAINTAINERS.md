# Maintainers

onepack is currently maintained by a single maintainer:

- **Cristian Mendez** ([@Khr0x](https://github.com/Khr0x)) — maintainer,
  release manager, and security contact.

## Responsibilities

- Review issues and pull requests.
- Keep CI, dependencies, and release artifacts in good shape.
- Triage security reports through GitHub private vulnerability reporting.
- Update the changelog and release notes before a release.

Response times are best effort. There is no commercial support offering.

## Contributions

Contributions are welcome under [CONTRIBUTING.md](CONTRIBUTING.md) and the
[Code of Conduct](CODE_OF_CONDUCT.md). Decisions are made through issues and
pull requests; large changes should be discussed before implementation.
