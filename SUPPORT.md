# Support

onepack is maintained on a best-effort basis.

- **Usage questions and bug reports:** open a
  [GitHub issue](https://github.com/Khr0x/onepack/issues). Use the bug report
  template for reproducible problems.
- **Feature requests:** open an issue with the feature request template before
  implementing a large change.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md). Do not open a
  public issue.
- **Documentation:** the [README](README.md) and [`docs/`](docs/) cover
  installation, the CLI, the API, security, operations, and release procedures.

There is no commercial support offering for this project.
