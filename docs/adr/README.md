# Architecture Decision Records

Architecture decisions are versioned with the source code and remain part of
the public repository. For v1 they stay in:

- [MVP ADRs: 001–020](../../roadmap/adr-mvp.md)
- [v2 ADRs: 021–026](../../roadmap/adr-v2.md)

Keeping the files in `roadmap/` preserves stable links while v1 is closing.
After v1, they can be split into individual `docs/adr/NNNN-*.md` files if the
project needs per-decision history; the decision and links will be updated in
the same change.

Do not duplicate ADRs in the Obsidian tracking vault. The vault tracks tasks;
the repository records decisions.
